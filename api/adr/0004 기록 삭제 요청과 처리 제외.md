# 0004. 기록 삭제 요청과 처리 제외

## Status

Draft, 2026.10.23. 처리 원칙 초안이며 기능은 아직 구현하지 않았다.

## Context

이용자가 자신의 기록 삭제를 요청하면, 삭제가 완료되기 전에도 해당 기록의 노출을 막아야 한다.

## Decision

삭제 요청 시 본인과 공유 상대의 열람을 먼저 차단하고 실제 삭제를 진행한다.
물리적 삭제 완료까지 기술적으로 필요한 시간이 걸릴 수 있으며,
필요한 조치를 지체 없이 진행한 뒤 처리 결과를 이용자에게 알린다.

## Consequences

열람 차단과 삭제 완료를 구분하며, 실제 삭제가 끝난 뒤 완료된 것으로 안내한다.
구체적인 화면과 처리 기능은 별도로 구현한다.
